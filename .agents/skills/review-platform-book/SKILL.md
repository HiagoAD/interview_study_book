# Review The Platform Layer

From this repository's root, read and follow
[the reader review plan](../../../docs/reader-review-plan.md).

With no narrower scope, review the whole second book from both the learner and
writing perspectives. Honor requests such as “chapter 8, section 2”, “writing
only”, or “resume” followed by an existing report directory. A partial review
must state its coverage and cannot assign a whole-book rating.

Write review artifacts only. The shared plan defines the audience, rubric,
chapter checkpoints, synthesis and editing-plan deliverables. It complements
Phase 35's technical review and does not authorize book or question edits.
